RONDA ONE CLOUD v0.8.0 — MESA EDITORIAL INTELIGENTE

ARQUIVO COMPLETO

Esta versão substitui a v0.7.9 como nova base do projeto.
Não aplique patches antigos por cima dela.

PASSOS
1. Faça backup do repositório.
2. Extraia este ZIP.
3. Envie todo o conteúdo para a raiz do GitHub.
4. Confirme que src/, public/, package.json e wrangler.jsonc ficaram na raiz.
5. Rode:

   npm install
   npm run check
   npm run verify:080

6. Se tudo estiver OK:

   npm run deploy

PRINCIPAL EVOLUÇÃO
- eventos editoriais persistentes;
- Mesa orientada a acontecimentos, não a URLs isoladas;
- informação nova e mudanças desde a última ronda;
- timeline;
- relevância e tração separadas;
- nível de confirmação baseado em sinais objetivos;
- divergências entre fontes;
- pontos em aberto e sugestões de pauta;
- histórico de eventos;
- produção editorial/carrossel com rastreabilidade.

COMPATIBILIDADE
- rotas atuais preservadas sempre que possível;
- tabelas atuais do D1 preservadas;
- fontes e monitoramentos atuais preservados;
- mesma ROUND_JOBS_QUEUE e INTELLIGENT_JOBS_QUEUE;
- FORMA DESIGN continua sem geração de imagem por IA;
- não há nova Queue obrigatória no Cloudflare.
