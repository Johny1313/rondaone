RONDA ONE 0.7 — GITHUB + CLOUDFLARE

Resumo rápido:
1. Crie o repositório GitHub `ronda-one`.
2. Extraia o ZIP e envie os arquivos para a raiz.
3. Configure o binding D1 DB no wrangler.jsonc com o ID real.
4. Cloudflare Workers & Pages > Create application > Import a repository.
5. Selecione `ronda-one`.
6. Production branch: main.
7. Root directory: vazio.
8. Build command: vazio.
9. Deploy command: npx wrangler deploy.
10. Save and Deploy.

Depois:
/ronda -> Editorial
/design/ -> Design
/projects/ -> Projects
/api/platform/status -> diagnóstico

Nenhuma instalação local de Node é necessária.
