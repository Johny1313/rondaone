RONDA ONE v0.8.6 — SMART TEMPLATES

Depois que um carrossel da RONDA está no FORMA DESIGN:
1. abra Templates
2. clique em um template
3. o mesmo conteúdo é redistribuído nos slots semânticos
4. o texto recebe Auto Fit
5. as imagens entram nos slots IMAGE
6. Reaplicar restaura o layout do template
7. Desvincular transforma a composição em objetos normais editáveis

Deploy:
npm install
npm run check
npm run verify:086
npm run test:086
npm run test:regression
npm run deploy
