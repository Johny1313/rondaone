RONDA ONE v0.8.4 — AUTH + PROFILE + DASHBOARD

ANTES DO PRIMEIRO LOGIN DO ADMIN:
1. No terminal autenticado no Cloudflare, execute:
   npx wrangler secret put ADMIN_BOOTSTRAP_PASSWORD
2. Quando solicitado, digite a senha administrativa definida pelo responsável.
3. Faça o primeiro login com o e-mail ADM.
4. Depois que o acesso estiver confirmado no D1, por segurança você pode remover o bootstrap:
   npx wrangler secret delete ADMIN_BOOTSTRAP_PASSWORD

A senha não é gravada no GitHub.

DEPLOY:
npm install
npm run check
npm run verify:084
npm run test:regression
npm run deploy
