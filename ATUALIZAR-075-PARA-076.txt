RONDA ONE 0.7.6 — UI RECOVERY / STALE QUEUE GUARD

Sintoma corrigido
- interface presa em "Reconectando à fila inteligente";
- job antigo do carrossel permanecendo no estado local;
- necessidade de atualizar manualmente a página;
- assets antigos permanecendo no cache do navegador.

Correções
1. Jobs locais com mais de 12 minutos deixam de bloquear a interface.
2. A tela principal tenta novamente /api/health, /api/status e /api/latest sem recarregar a página.
3. O botão Executar ronda é liberado quando não existe execução real ativa.
4. O polling de carrossel continua resiliente; tarefas stale são encerradas apenas na UI e uma nova tentativa pode começar.
5. Cache bust de app.js/styles.css e integração 0.7.6.
6. O Worker, D1, Queues, IA e cron não foram alterados.

Instalação
- envie todos os arquivos deste ZIP para a raiz do repositório rondaone;
- substitua os existentes;
- aguarde o Cloudflare Build;
- não altere wrangler.jsonc, DB, AI ou Queues.

Teste
/api/platform/status?t=076
Esperado:
version = 0.7.6
uiRecovery.automatic = true
uiRecovery.reloadRequired = false

Depois abra /ronda. Uma tela presa em reconexão deve se recuperar sozinha sem F5.
